# NovaCloud – B2B AI & Developer Cloud SaaS Landing Page

A modern, high-converting B2B SaaS landing page built for AI autonomous agent runtimes, serverless microVM orchestration, and cloud infrastructure platforms.

Designed with Stripe, Linear, and Vercel-grade design systems.

---

## 🚀 Key Features

1. **Floating Glassmorphic Header:** Real-time scroll blur, responsive mobile navigation drawer, and persistent Dark/Light theme switcher.
2. **Interactive Code Sandbox Terminal:** Switch between Node.js, Python, and Go agent runtimes with copy-to-clipboard functionality and syntax highlighting.
3. **Enterprise Social Proof & Stats Bar:** Real-time metrics (99.999% SLA, <12ms Edge Latency, 4.8B+ Daily Requests) and partner logos.
4. **Interactive Architecture Feature Tabs:** Tabbed showcase switching between Isolated MicroVMs, Anycast Geo-Routing, Distributed Cache, and Predictive Auto-scaling with live topology simulation.
5. **Interactive Cloud ROI & Savings Calculator:** Dynamic range sliders (1M–100M invocations, 10GB–1,000GB storage) demonstrating real-time cost savings compared to legacy AWS/GCP hyperscalers.
6. **Monthly/Annual Pricing Switcher:** 25% discount calculation logic across Developer ($0), Pro Team ($49/mo), and Enterprise Cloud ($299/mo) tiers.
7. **Social Proof & Testimonial Grid:** Authentic engineering leader reviews with strictly neutral SVG `<User />` silhouettes.
8. **Filterable Accordion FAQ:** Real-time keyword filter input for questions on latency, migration, and compliance.
9. **Interactive 14-Day Free Trial Modal:** Client-side validation, simulated API key generation, local storage persistence, and celebration confetti.
10. **Pre-configured Vercel Routing:** Clean `vercel.json` rewrite file preventing 404s on page reloads.

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server on port 5180
npm run dev

# Build production bundle
npm run build
```

---

## 🌐 Deploy to Vercel

```bash
npx vercel --prod --yes
```
